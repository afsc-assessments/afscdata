# BSAI Atka mackerel historical catch

A dataset containing historical catch data by year for 1977-1990, pulled
from 2022 stock assessment data file.

## Usage

``` r
bsai_amak_catch_1977_1990
```

## Format

A data frame with 14 observations and 2 variables:

- year:

  1977-1990

- catch:

  catch in tons
