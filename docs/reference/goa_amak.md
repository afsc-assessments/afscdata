# raw data query for the GOA Atka mackerel assessment

raw data query for the GOA Atka mackerel assessment

## Usage

``` r
goa_amak(year)
```

## Arguments

- year:

  assessment year

## Value

a suite of raw data .csv files and a time stamp of when the query was
done

## Examples

``` r
if (FALSE) { # \dontrun{
goa_amak(year = 2023)
} # }
```
