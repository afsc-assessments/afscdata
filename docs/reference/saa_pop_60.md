# GOA POP historical size at age parameters data

A dataset containing size at age parameters for POP \<= 1960

## Usage

``` r
saa_pop_60
```

## Format

A data frame with 1 observations and 5 variables:

- linf:

  von B parameter

- k:

  von B parameter

- t0:

  von B parameter

- a:

  a parameter

- b:

  b parameter
