# GOA Pacific cod historical catch

A dataset containing historical catch data by year for 1977-1990

## Usage

``` r
goa_pcod_catch_1977_1990
```

## Format

A data frame with 280 observations and 4 variables:

- tons:

  catch in tons

- gear:

  fishery gear type

- year:

  1977-1990

- season:

  quarterly fishery season
