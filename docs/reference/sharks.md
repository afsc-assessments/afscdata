# raw data query for GOA/BSAI sharks

raw data query for GOA/BSAI sharks

## Usage

``` r
sharks(year, area)
```

## Arguments

- year:

  assessment year

- area:

  what region? eith goa or bsai

## Value

a suite of raw data .csv files and a time stamp of when the query was
done

## Examples

``` r
if (FALSE) { # \dontrun{
sharks(year = 2023, area = "goa")
} # }
```
